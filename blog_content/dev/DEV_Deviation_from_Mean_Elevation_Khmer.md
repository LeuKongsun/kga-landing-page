# DEV (Deviation from Mean Elevation)៖ ការវិភាគភូមិសាស្ត្រកម្ពស់សម្រាប់កសិកម្មឆ្លាតវៃ

**រយៈពេលអានប្រហែល៖ ១៥ នាទី**

## សេចក្តីផ្តើម

DEM (Digital Elevation Model) គឺជាទិន្នន័យមូលដ្ឋានសំខាន់សម្រាប់ការវិភាគផ្ទៃដី។ ក្រៅពី Slope, Aspect និង Flow Accumulation នៅមានសូចនាករមួយទៀតដែលមានប្រយោជន៍ខ្លាំងគឺ **Deviation from Mean Elevation (DEV)**។

DEV មិនវាស់កម្ពស់ដាច់ខាតទេ ប៉ុន្តែវាវាស់ថា តើទីតាំងនីមួយៗខ្ពស់ ឬទាបជាងតំបន់ជុំវិញខ្លួនប៉ុន្មាន។ ដូច្នេះវាអាចបង្ហាញលម្អិតអំពី Ridge, Valley និង Micro-topography ដែលមើលមិនសូវឃើញពី DEM ដើម។

---

# DEV ជាអ្វី?

DEV គឺជា z-score នៃកម្ពស់ធៀបនឹងមធ្យមភាគកម្ពស់ក្នុង Neighborhood។

រូបមន្ត៖

DEV = (កម្ពស់ក្រឡា − មធ្យមកម្ពស់ជុំវិញ) / គម្លាតស្តង់ដារកម្ពស់

ការបកស្រាយ៖

- DEV > +2 = ខ្ពស់ជាងតំបន់ជុំវិញខ្លាំង
- DEV ≈ 0 = ស្រដៀងតំបន់ជុំវិញ
- DEV < -2 = ទាបជាងតំបន់ជុំវិញខ្លាំង

---

# ហេតុអ្វីមិនប្រើ Elevation តែមួយ?

Elevation ប្រាប់ថា "កម្ពស់ពីនីវ៉ូសមុទ្រ"។

DEV ប្រាប់ថា "ខ្ពស់ ឬទាបជាងតំបន់ជុំវិញ"។

នេះជាភាពខុសគ្នាសំខាន់សម្រាប់ការយល់ដឹងពីរចនាសម្ព័ន្ធផ្ទៃដី។

---

# របៀបដំណើរការ

1. បញ្ចូល DEM
2. កំណត់ Search Radius
3. គណនាមធ្យមកម្ពស់
4. គណនា Standard Deviation
5. គណនា DEV

លទ្ធផលគឺ Raster បង្ហាញតំបន់ខ្ពស់ និងទាបក្នុងលក្ខណៈប្រៀបធៀប។

---

# ការបកស្រាយលទ្ធផល

## DEV វិជ្ជមាន

បង្ហាញ៖

- Ridge
- Knoll
- តំបន់ខ្ពស់

ជាទូទៅមានការបង្ហូរទឹកល្អ ប៉ុន្តែងាយរងការកាត់សំណឹក។

## DEV ស្មើសូន្យ

បង្ហាញផ្ទៃដីដែលស្រដៀងនឹងតំបន់ជុំវិញ។

## DEV អវិជ្ជមាន

បង្ហាញ៖

- Valley
- Depression
- តំបន់ប្រមូលទឹក

សមស្របសម្រាប់ការវិភាគការលិចទឹក និងការរៀបចំប្រព័ន្ធបង្ហូរទឹក។

---

# Search Radius

Radius តូច៖

- លម្អិតខ្ពស់
- មើលឃើញ Micro-topography
- Noise ច្រើន

Radius ធំ៖

- លទ្ធផលរលូន
- មើលទិដ្ឋភាពទូលំទូលាយ
- លម្អិតតិចជាង

---

# អត្ថប្រយោជន៍សម្រាប់ Precision Agriculture

- កំណត់តំបន់ប្រមូលទឹក
- រចនាប្រព័ន្ធបង្ហូរទឹក
- Variable Rate Application
- វាយតម្លៃហានិភ័យកាត់សំណឹក
- ជ្រើសរើសទីតាំងផ្លូវ ស្រះ និងហេដ្ឋារចនាសម្ព័ន្ធ

# Best Practices

- ប្រើ DEM ដែលមានគុណភាពល្អ
- ជ្រើស Radius សមស្រប
- សម្អាត DEM មុនវិភាគ
- ផ្ទៀងផ្ទាត់ជាមួយទិន្នន័យវាល
- ប្រើរួមជាមួយ Terrain Indices ផ្សេងៗ

# ឧទាហរណ៍អនុវត្ត

កសិកម្ម៖ កំណត់តំបន់សើម កែលម្អប្រព័ន្ធស្រោចស្រព និងកាត់បន្ថយការប្រើជី។

ធនធានទឹក៖ កំណត់ផ្លូវទឹក និងតំបន់ប្រមូលទឹក។

វិស្វកម្ម៖ ជ្រើសរើសទីតាំងសាងសង់ និងគណនាការកែសម្រួលដី។

បរិស្ថាន៖ សិក្សាការកាត់សំណឹក និងជម្រកធម្មជាតិ។

# សេចក្តីសន្និដ្ឋាន

DEV គឺជាសូចនាករដ៏មានអត្ថប្រយោជន៍សម្រាប់ការវិភាគភូមិសាស្ត្រផ្ទៃដី។ វាជួយបង្ហាញភាពខុសគ្នានៃកម្ពស់ក្នុងតំបន់ជុំវិញ ដែលមានសារៈសំខាន់សម្រាប់ការគ្រប់គ្រងទឹក ការកាត់សំណឹក ការរៀបចំដី និង Precision Agriculture។
