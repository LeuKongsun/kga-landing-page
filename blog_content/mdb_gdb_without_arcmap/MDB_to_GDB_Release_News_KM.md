# ព័ត៌មានចេញផ្សាយ៖ បម្លែង MDB ទៅ GDB ដោយមិនចាំបាច់បើក ArcMap

**រយៈពេលអាន៖** ប្រហែល ៥ នាទី  
**ប្រភេទអត្ថបទ៖** ព័ត៌មានចេញផ្សាយ

## វិធីថ្មីសម្រាប់បម្លែងទិន្នន័យចាស់ទៅ File Geodatabase

អង្គភាព GIS ជាច្រើននៅតែរក្សាទុកទិន្នន័យជា **Personal Geodatabase (.mdb)** ដែលបង្កើតពី ArcMap។ កន្លងមក ការបម្លែងទៅជា **File Geodatabase (.gdb)** តម្រូវឱ្យបើក ArcMap សិន បន្ទាប់មកទើប Export និង Import ទិន្នន័យ។

ដំណើរការនេះចំណាយពេល និងពឹងផ្អែកលើកម្មវិធីដែល Esri បានបញ្ឈប់ការអភិវឌ្ឍរួចហើយ។

ថ្ងៃនេះ KGA Toolbox នាំមកនូវដំណោះស្រាយថ្មី។

## មុខងារថ្មី

ឧបករណ៍ **MDB to GDB** អាចបម្លែង Personal Geodatabase ទៅជា File Geodatabase ដោយផ្ទាល់ **ដោយមិនចាំបាច់បើក ArcMap**។

អ្នកគ្រាន់តែ៖

1. ជ្រើសរើសឯកសារ `.mdb`
2. កំណត់ទីតាំងរក្សាទុក
3. ចុច **Convert**

ឧបករណ៍នឹងបង្កើត File Geodatabase និងផ្ទេរទិន្នន័យដែលគាំទ្រដោយស្វ័យប្រវត្តិ។

## ហេតុអ្វីវាសំខាន់?

- ArcMap ត្រូវបានបញ្ឈប់ការអភិវឌ្ឍ។
- ArcGIS Pro មិនបង្កើត Personal Geodatabase ទៀតទេ។
- គម្រោងចាស់ៗជាច្រើននៅតែប្រើ MDB។

ឧបករណ៍នេះជួយកាត់បន្ថយការងារដោយដៃ និងធ្វើឱ្យការផ្លាស់ប្តូរទៅ ArcGIS Pro កាន់តែងាយស្រួល។

## អត្ថប្រយោជន៍

- ✅ មិនចាំបាច់បើក ArcMap
- ✅ បម្លែងបានលឿន
- ✅ សាកសមសម្រាប់គម្រោងច្រើន
- ✅ ជួយផ្លាស់ប្តូរទៅ File Geodatabase បានងាយ
- ✅ សមស្របសម្រាប់ Workflow របស់ ArcGIS Pro

## អាចប្រើសម្រាប់

- បម្លែងទិន្នន័យ GIS ចាស់
- រៀបចំទិន្នន័យសម្រាប់ ArcGIS Pro
- ធ្វើស្តង់ដារមូលដ្ឋានទិន្នន័យរបស់អង្គភាព
- រក្សាទុកទិន្នន័យក្នុងទម្រង់ទំនើប

## Workflow ថ្មី

ជំនួសឱ្យ

**Open ArcMap → Export → Create GDB → Import**

ឥឡូវនេះ អ្នកគ្រាន់តែ

**Select MDB → Convert → Done**

ងាយ សាមញ្ញ និងចំណេញពេលវេលាជាងមុន។

## សេចក្តីសន្និដ្ឋាន

ការផ្លាស់ប្តូរទិន្នន័យចាស់ទៅកាន់ File Geodatabase គឺជាជំហានសំខាន់សម្រាប់អង្គភាពដែលកំពុងប្រើ ArcGIS Pro។ ឧបករណ៍ MDB to GDB របស់ KGA Toolbox ត្រូវបានបង្កើតឡើងដើម្បីធ្វើឱ្យការងារនេះកាន់តែលឿន ងាយស្រួល និងអាចទុកចិត្តបាន។

ប្រសិនបើអ្នកនៅតែមានទិន្នន័យ MDB ចាស់ៗ នេះគឺជាពេលល្អបំផុតក្នុងការបម្លែងវាទៅកាន់ File Geodatabase។
