# សន្សំពេលវេលាបានរហូតដល់ 80% ក្នុងការធ្វើការជាមួយ KML ដោយប្រើ KGA Toolbox

**ប្រភេទអត្ថបទ៖** ព័ត៌មានអំពីការចេញមុខងារថ្មី  
**រយៈពេលអាន៖** ប្រហែល ៥ នាទី  
**រយៈពេលវីដេអូ៖** 5:02

## សេចក្តីផ្តើម

KML (Keyhole Markup Language) គឺជាទម្រង់ទិន្នន័យភូមិសាស្ត្រដែលត្រូវបានប្រើយ៉ាងទូលំទូលាយនៅក្នុង Google Earth។ អ្នកជំនាញ GIS ជាច្រើនទទួលទិន្នន័យដីធ្លី ព្រំប្រទល់គម្រោង ឬទិន្នន័យស្ទង់មតិជាទម្រង់ KML/KMZ ហើយត្រូវយកមកប្រើក្នុង ArcGIS Pro។

ការបម្លែង និងរៀបចំទិន្នន័យទាំងនេះដោយដៃអាចចំណាយពេលច្រើន។ ដើម្បីដោះស្រាយបញ្ហានេះ **KGA Toolbox** បានបន្ថែម **KML Handler Tool** ដែលអាចជួយកាត់បន្ថយការងារដដែលៗ និងធ្វើឱ្យដំណើរការលឿនជាងមុន។

## បញ្ហាដែលជួបប្រទះ

វិធីធម្មតាត្រូវ៖

- Import KML/KMZ ម្តងមួយៗ
- រៀបចំ Feature Class ឡើងវិញ
- បង្កើត Folder ដោយដៃ
- ធ្វើដំណើរការដដែលៗសម្រាប់ឯកសារជាច្រើន

ការងារទាំងនេះចំណាយពេល និងងាយមានកំហុស។

## KGA Toolbox ជួយដូចម្តេច?

KML Handler Tool ផ្តល់សមត្ថភាពដូចជា៖

- គាំទ្រ KML និង KMZ
- បម្លែងដោយផ្ទាល់ទៅ File Geodatabase
- រក្សាទុក Folder Structure តាមដែលអាចធ្វើបាន
- រៀបចំ Output ដោយស្វ័យប្រវត្តិ
- កាត់បន្ថយការងារក្រោយការបម្លែង
- អាចប្រើភ្លាមក្នុង ArcGIS Pro

## សាកសមសម្រាប់ការងារអ្វីខ្លះ?

- ការគ្រប់គ្រងដីធ្លី
- ការរៀបចំផែនការទីក្រុង
- ការតាមដានបរិស្ថាន
- ការស្ទង់មតិវិស្វកម្ម
- Utility Mapping
- អង្គភាពរដ្ឋ និងឯកជនដែលប្រើ Google Earth

## ហេតុអ្វីគួរប្រើ?

ការកាត់បន្ថយការងារដដែលៗ អនុញ្ញាតឱ្យអ្នកផ្តោតលើការវិភាគទិន្នន័យជំនួសការរៀបចំទិន្នន័យ។ វាក៏ជួយធ្វើឱ្យ Workflow មានស្តង់ដារ និងកាត់បន្ថយកំហុសក្នុងការងារផងដែរ។

## មើលវីដេអូសាកល្បង

វីដេអូរយៈពេល **5:02** បង្ហាញពីការប្រើប្រាស់ **KGA Toolbox – KML Handler Tool** ចាប់ពីការនាំចូល KML រហូតដល់ទទួលបានទិន្នន័យដែលអាចប្រើបានក្នុង ArcGIS Pro។

អ្នកនឹងឃើញ៖

1. របៀប Import KML
2. ការរៀបចំទិន្នន័យដោយស្វ័យប្រវត្តិ
3. លទ្ធផលចុងក្រោយក្នុង ArcGIS Pro

## សេចក្តីសន្និដ្ឋាន

ប្រសិនបើអ្នកធ្វើការជាមួយទិន្នន័យ Google Earth ជាប្រចាំ **KML Handler Tool** ក្នុង **KGA Toolbox** អាចជួយសន្សំពេលវេលា បង្កើនប្រសិទ្ធភាពការងារ និងធ្វើឱ្យការគ្រប់គ្រងទិន្នន័យកាន់តែងាយស្រួល។
