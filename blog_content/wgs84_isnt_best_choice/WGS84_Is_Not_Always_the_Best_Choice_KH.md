# គន្លឹះ GIS #5៖ WGS84 មិនមែនជាជម្រើសល្អបំផុតសម្រាប់គ្រប់ការងារទេ

**រយៈពេលអានប្រហែល៖ ៦ នាទី**

## សេចក្តីផ្តើម

អ្នកចាប់ផ្តើម GIS ជាច្រើនយល់ថា **WGS84** គឺជាប្រព័ន្ធកូអរដោនេល្អបំផុតសម្រាប់គ្រប់ការងារ ព្រោះ GPS និង Google Maps ប្រើវា។ ប៉ុន្តែការពិត វាល្អសម្រាប់ការបង្ហាញទីតាំង និងការចែករំលែកទិន្នន័យ ប៉ុណ្ណោះ មិនមែនសម្រាប់ការវាស់វែង និងវិភាគទាំងអស់ឡើយ។

---

## WGS84 ជាអ្វី?

WGS84 គឺជា **Geographic Coordinate System (GCS)** ដែលប្រើ Latitude និង Longitude ហើយឯកតាជា **ដឺក្រេ (°)**។

វាត្រូវបានប្រើយ៉ាងទូលំទូលាយក្នុង៖

- GPS
- Google Maps
- ArcGIS Online
- OpenStreetMap
- ការចែករំលែកទិន្នន័យ

---

## ហេតុអ្វី WGS84 មិនសមស្របសម្រាប់ការវាស់វែង?

ដឺក្រេមិនមែនជាឯកតាចម្ងាយទេ។

តម្លៃ ១ ដឺក្រេ មិនស្មើគ្នាទូទាំងពិភពលោក ដូច្នេះការគណនាចម្ងាយ ផ្ទៃក្រឡា Buffer និង Spatial Analysis អាចមានកំហុស។

សម្រាប់ការបង្ហាញផែនទី វាមិនមែនជាបញ្ហាធំទេ ប៉ុន្តែសម្រាប់ការងារវិស្វកម្ម និងវិភាគ វាអាចប៉ះពាល់ដល់លទ្ធផល។

---

## Projected Coordinate System

Projected Coordinate System បម្លែងផ្ទៃកោងរបស់ផែនដីទៅលើផ្ទៃរាប ហើយប្រើឯកតា **ម៉ែត្រ (m)** ឬ **ហ្វីត**។

ឧទាហរណ៍៖

- UTM
- National Grid
- State Plane

ប្រព័ន្ធទាំងនេះផ្តល់លទ្ធផលត្រឹមត្រូវជាងសម្រាប់ការគណនា។

---

## ពេលណាគួរប្រើ WGS84?

ប្រើ WGS84 សម្រាប់៖

- បង្ហាញផែនទី
- Web Map
- GPS
- Mobile App
- ចែករំលែកទិន្នន័យ

---

## ពេលណាគួរប្រើ Projected Coordinate System?

ប្រើ Projected Coordinate System សម្រាប់៖

- វាស់ចម្ងាយ
- គណនាផ្ទៃក្រឡា
- Buffer
- Overlay Analysis
- Spatial Analysis
- ការងារវិស្វកម្ម និងសុរិយោដី

---

## ឧទាហរណ៍ជាក់ស្តែង

បើអ្នកវាស់ប្រវែងផ្លូវដោយប្រើ WGS84 ការគណនានឹងផ្អែកលើដឺក្រេ។

បើ Project ទៅជា UTM សិន ការគណនានឹងប្រើម៉ែត្រ ដែលមានភាពត្រឹមត្រូវជាង និងសមស្របសម្រាប់ការវិភាគ។

---

## កំហុសដែលអ្នកចាប់ផ្តើមជួបញឹកញាប់

- Buffer ក្នុង WGS84

- គិតថា Coordinate ពី Google Maps អាចប្រើសម្រាប់គ្រប់ការងារ

## សេចក្តីសន្និដ្ឋាន

មិនមាន Coordinate System ណាមួយល្អបំផុតសម្រាប់គ្រប់ការងារទេ។

- ចង់បង្ហាញ និងចែករំលែកទិន្នន័យ → WGS84
- ចង់វាស់វែង និងវិភាគឲ្យបានត្រឹមត្រូវ → Projected Coordinate System
