Toolbox Categories

Each category groups related GIS operations into a focused, production-ready module designed for cadastral, engineering, and spatial workflows.

KGABasicDataCreation

Generate foundational GIS datasets including points, lines, polygons, and annotation layers from scratch.

KGACadastral

Cadastral-specific tools for parcel management, boundary adjustments, and land survey data processing.

KGAConverter

Convert between formats — shapefile, GeoJSON, KML, and geodatabase feature classes with precision.

KGACRS

Coordinate Reference System tools — detect, assign, reproject, and harmonize spatial references across datasets.

KGADataCreation

Advanced data creation with schema templates, attribute population, and domain-driven feature generation.

KGADataManagement

Manage geodatabases, feature classes, domains, subtypes, and attribute rules at enterprise scale.

KGAGeoprocessing

Clip, buffer, dissolve, intersect, and merge operations with smart defaults and batch processing support.

KGAMapping

Automate map production — symbology, labeling, layout generation, and multi-page map series export.

KGAQC

Quality Control checks — validate attributes, geometry integrity, schema conformance, and data completeness.

KGASpatialAnalysis

Proximity, overlay, direction-based selection, and spatial statistics for complex analytical workflows.

KGATopologyCheck

Detect gaps, overlaps, dangles, and self-intersections with automated topology rule validation.

About

Built for GIS Professionals

KGA Toolbox is a Python-based ArcGIS Pro toolbox (.pyt) built by GIS engineers for GIS engineers. It eliminates repetitive tasks, enforces data quality standards, and accelerates production workflows in cadastral, infrastructure, and environmental mapping projects.
