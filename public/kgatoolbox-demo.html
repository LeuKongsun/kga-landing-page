Tips & Tricks 05 May 2026

5 Tips to Speed Up Your CRS Conversion

The KGAConverter module handles coordinate system transformations across dozens of projection systems. Here are the five workflow shortcuts every user should know.

  1. Pre-load your output CRS profile in the Settings tab — this saves 2 clicks per tool run.
  2. Use Batch Conversion mode to process entire folders instead of individual layers.
  3. Enable Preserve Original to keep source files intact in a _backup subfolder.
  4. Select only the fields you need when exporting — this cuts file size by up to 40%.
  5. Pin the Converter panel to your ArcGIS Pro sidebar for one-click access without reopening the toolbox.

ℹ️ Note

The KGAConverter supports all EPSG-registered CRS codes. If your projection is missing, contact us via Telegram for a custom addition.

How to Run a Topology Check on Your Parcel Layer

Topology errors are one of the most common causes of failed cadastral submissions. This guide walks you through using KGATopology to detect and fix errors before publishing.

What is a Topology Check?

A topology check validates the geometric relationships between features in your GIS dataset — ensuring parcels don't overlap, gaps don't exist between boundaries, and slivers are detected automatically.

Why it Matters

Government agencies and land registry offices require clean topology for parcel submissions. Even a single overlapping vertex can cause a full rejection of your dataset. The KGATopology tool automates this check and generates an error report with visual highlights inside ArcGIS Pro.

  1. Open the KGA Toolbox in ArcGIS Pro and navigate to KGATopology → Run Topology Check.
  2. Select your target feature class (e.g., Parcel_Boundary) as the input layer.
  3. Choose the rule set: Must Not Overlap, Must Not Have Gaps, Must Be Covered By.
  4. Set the cluster tolerance — use 0.001m for cadastral-grade accuracy.
  5. Click Run. The tool highlights errors directly in the map view with color-coded symbols.
  6. Export the Error Report as a CSV or PDF for documentation.

💡 Pro Tip

Run topology checks on a copy of your dataset first. This lets you review errors without modifying production data accidentally.
